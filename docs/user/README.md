# Documentación de usuario de Iris

Documentación para los operadores que usan Iris para monitorear el envío de mensajes SMS, WhatsApp y Email.

- [Manual del operador](manual-operador.md): se construye sección por sección con cada tarea que cambia algo visible y se consolida en [F5-05](../roadmap/F5-release/F5-05-manual-operador.md).
- Notas de versión: `docs/releases/` (la primera es `v0.1.0`, en [F5-07](../roadmap/F5-release/F5-07-release-v0-1-0.md)).

## Reglas para escribir esta documentación

- Escribir para el operador: qué ve, qué puede hacer y qué significa cada dato. Sin términos como "BFF", "signal" o "endpoint".
- Una sección por pantalla o tarea del operador, con captura en tema claro.
- Cada mensaje de error que puede ver el operador aparece con su explicación y qué hacer.
